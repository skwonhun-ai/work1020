# 📊 예산 분석 인터랙티브 대시보드 (Web)

본 대시보드는 엑셀(`.xlsx`, `.xls`) 및 `CSV` 형태의 예산 데이터를 입력받아 **분야별(중점영역)** 및 **신규사업별** 현황을 인터랙티브하게 분석하고 시각화하는 웹 애플리케이션입니다.

---

## 🚀 빠른 시작

1. `web/index.html` 파일을 크롬, 엣지(Edge) 등 웹 브라우저로 더블 클릭하여 엽니다.
   - 또는 `web/대시보드_실행.bat`을 실행합니다.
2. 페이지 로드 즉시 기본 탑재된 **2027년 국방예산 데이터(22개 사업)** 가 시각화되어 대시보드가 표출됩니다.
3. 상단의 드래그 앤 드롭 영역 또는 `파일 선택` 버튼을 통해 새로운 엑셀/CSV 파일을 업로드하면 즉시 새 데이터로 대시보드가 갱신됩니다.

---

## 📂 폴더 구조

```
web/
├── index.html                 # 메인 웹 대시보드 페이지
├── 대시보드_실행.bat           # 원클릭 실행 스크립트
├── css/
│   └── style.css              # 모던 UI/다크모드 지원 스타일시트
├── js/
│   ├── app.js                 # UI 이벤트 처리 및 상태 관리
│   ├── charts.js              # Chart.js 시각화 차트 매니저
│   └── data-parser.js         # 엑셀/CSV 스마트 컬럼 자동 감지 및 파서
├── data/
│   ├── default_data.js        # 기본 내장 샘플 데이터 (2027년 국방예산)
│   ├── default_data.json      # 기본 JSON 데이터
│   └── sample_template.csv    # 사용자 입력용 CSV 양식 템플릿
└── lib/
    ├── chart.umd.min.js       # Chart.js 로컬 라이브러리 (오프라인 지원)
    └── xlsx.full.min.js       # SheetJS 로컬 라이브러리 (오프라인 지원)
```

## 🎯 주요 기능 및 특징

### 1. 유연한 파일 입력 & 스마트 자동 인식
- **지원 포맷**: Excel(`.xlsx`, `.xls`), CSV(`.csv`)
- **드래그 앤 드롭**: 마우스로 파일을 끌어다 놓기만 하면 즉시 파싱
- **스마트 컬럼 매칭**:
  - `연번`, `분야(중점영역)`, `세부 사업명`, `단위`, `2026년(A)`, `2027년 정부안(B)`, `증감(B-A)`, `증가율(%)`, `핵심 내용/원문 근거`
  - 컬럼 명칭이 다소 달라도 별칭(Alias) 사전을 통해 자동으로 매칭

### 2. 4가지 특화 뷰 (탭 네비게이션)
1. **📊 종합 개요 (Overview)**:
   - 5대 핵심 KPI (분석 대상 사업 수, 2026년 본예산, 2027년 정부안, 총 증감액/증가율, 신규 과제 예산 및 비중)
   - 분야별 예산 비교 막대 차트 (2026 vs 2027)
   - 분야별 2027년 예산 비중 점유율 (Doughnut)
   - 기존 지속사업 vs 신규 착수과제 예산 구성비
   - 전년 대비 증액 상위 Top 5 사업 수평 막대 차트
2. **🏢 분야별 대시보드 (Sector Analysis)**:
   - 분야별 필터 알약 버튼 (원클릭 필터링)
   - 각 분야별 카드 및 세부사업 목록, 2026 vs 2027 예산/증감액 통계 카드
3. **🚀 신규사업 집중 분석 (New Projects)**:
   - 2027년도 신규 착수/신설 과제(8개 과제) 전용 대시보드
   - 신규사업 예산 규모 순위 차트 (Top Ranking)
   - 분야별 신규사업 예산 분포 차트 (Polar Area)
   - 신규사업 상세 인터랙티브 카드 그리드 (클릭 시 원문 근거 팝업)
4. **📋 상세 데이터 조회 (Explorer)**:
   - 실시간 통합 키워드 검색
   - 분야별 / 사업유형별(신규만/기존만) 필터링
   - 컬럼별 오름차순/내림차순 정렬 (연번, 사업명, 예산, 증감, 증가율)
   - 각 행 클릭 시 모달 팝업으로 전체 보도자료 원문 근거 열람
   - 데이터 다시 Excel로 내보내기 기능

### 3. 완전한 독립 동작 (100% 오프라인 지원)
- 인터넷이 연결되지 않은 인트라넷, 폐쇄망, 오프라인 환경에서도 `lib/` 폴더 내에 번들된 자바스크립트 라이브러리(`xlsx.full.min.js`, `chart.umd.min.js`)를 통해 완벽하게 작동합니다.

### 4. 사용자 편의성
- **다크 모드 / 라이트 모드**: 우측 상단 버튼으로 즉시 전환 (설정 자동 기억)
- **인쇄 및 PDF 저장**: `@media print` 스타일 최적화로 깔끔한 보고서 출력 지원
- **양식 다운로드**: 사용자가 작성할 수 있는 `예산입력양식_템플릿.csv` 즉시 다운로드 제공
